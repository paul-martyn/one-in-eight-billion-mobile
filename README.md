# One in Eight Billion — мобильная веб-версия

Новый портретный интерфейс One in Eight Billion, подключённый к оригинальной игровой логике **1in8b.life 0.8.98 beta** (снимок 31 октября 2026). Под капотом работает **производный core**: тело оригинальной сборки без изменений, обёрнутое в контролируемое окружение. Экраны — перенос макетов холста «One in Eight Billion — Design» (страница Production) на React. Позже приложение будет реализовано в Unity; этот проект готовит экранный flow, спецификации и проверочные сценарии.

## Запуск

Стек: React 19.3.1, TypeScript 7.0.2, Vite 8.3.5, Motion for React 14.2.0. Node.js 24.16.0; точные версии закреплены в `package-lock.json`.

```powershell
npm ci
npm run dev
```

Адрес разработки: <http://127.0.0.1:4190/>. Сокращённое движение для проверки: <http://127.0.0.1:4190/?motion=reduced>.

| Команда | Назначение |
|---|---|
| `npm run dev` | генерация производного core и сервер разработки на `127.0.0.1:4190` |
| `npm run build` | проверка эталона, генерация core, проверка типов, сборка Vite |
| `npm run verify:build` | после сборки: минифицированный чанк core проходит те же 11 сценариев |
| `npm run preview` | просмотр готовой сборки на `127.0.0.1:4191` |
| `npm run check` | эталон, генерация core, типы, все тесты |
| `npm test` | тесты: эквивалентность core, команды против обработчиков оригинала, адаптер, ориентация |
| `npm run test:equivalence` | только сравнение оригинала и производного core |
| `npm run core:extract` | получить `src/core/generated/` из эталона (`--check` — сверить) |
| `npm run verify:core` | SHA-256 эталона и границы UI → адаптер → core |

Это самостоятельный локальный Git-репозиторий. Удалённый репозиторий и публикация не настроены.

## Что работает

- Оригинальная симуляция в браузере без старого интерфейса, сервера и сети. Сохранения в формате оригинала `{S, at}` под отдельным пространством ключей `1in8b-mobile/v1:`. Перезагрузка продолжает ту же жизнь и тот же поток случайности.
- Путь жизни по холсту v107: язык и валюта (первый запуск) → старт → рулетка страны → свидетельство о рождении → «Your odds» → жизнь (время, события, решения, пауза, скорости оригинала, «до следующего решения», Skip to the end) → вкладки People, Activities и Money (фокус года и лист «Spend & invest» оригинала с подтверждением рискованных пунктов), Odds → окно «Life ended» → итог жизни «This life» → хаб с наградой «A life lived» и Claim → новая жизнь.
- Мобильная мета-экономика (`src/adapters/meta.ts`): новая жизнь стоит 1 энергии из 5, восстановление +1 раз в 30 минут (временное значение), доллары и кристаллы начисляются наградой за жизнь. Слой не влияет на симуляцию.
- Настройки следующей жизни: эпоха, режим рождения, длина жизни 10 или 30 минут; язык и валюта.
- Люди нарисованы генератором персонажей команды (`src/ui/people`): пол, возраст и оттенок кожи — из игры.
- Подробные статусы экранов, расхождения макетов с оригиналом и вопросы по недостающим экранам: [карта экранов](docs/screen-map.md).

## Карта проекта

| Путь | Назначение |
|---|---|
| `src/core/` | хост производного core: окружение, поток случайности, загрузка; `generated/` создаётся генератором |
| `src/adapters/` | команды (повторяют обработчики старого UI), HOOK, игровые часы, снимки, view models, журнал команд |
| `src/flow/` | экранный flow и переходы |
| `src/screens/`, `src/ui/` | экраны и общие элементы в стиле макетов |
| `src/design/` | `tokens.json` и `motion.json` — общие с будущим Unity |
| `src/i18n/` | тексты нового интерфейса (пока только английский) |
| `design/claude-canvas/` | исходники макетов холста и ассеты с SHA-256 |
| `reference/` | неизменяемый эталон 0.8.98 и provenance |
| `tools/core/` | генератор производного core и анализ областей видимости |
| `tools/harness/` | оригинал в `node:vm`, сценарии, проверка сборки, воспроизведение журнала |
| `tests/core/` | эквивалентность, команды (включая лист трат и Skip to the end против обработчиков оригинала), адаптер, поток случайности, лист трат |
| `tools/people/` | извлечение генератора персонажей в манифест и атласы `src/assets/people/` |

## Ограничения

- Портретная композиция 393 × 852, ширины 320–430; на desktop — та же рамка. В альбомной ориентации на телефоне — просьба повернуть экран; клавиатура не считается поворотом; поворот не размонтирует игру.
- Работает только английский язык: игровые тексты приходят из английской сборки оригинала, тексты нового интерфейса не переведены на остальные 18 языков.
- Серверные функции оригинала (общая статистика, облачные копии, мемориалы, деревни, покупки) не восстановлены и не вызываются. Четыре жизни «той же секунды» — локальная симуляция, не реальные игроки.
- Будущий Unity-порт потребует отдельной реализации и проверки по тем же сценариям; автоматической конвертации JavaScript в C# нет.
