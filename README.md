# One in Eight Billion — мобильная игра

Портретный симулятор жизни с локальным движком, пятью языками, решениями, семьёй, учёбой, работой и экономикой. React-интерфейс обращается к движку через адаптер; прогресс сохраняется в браузере.

Приложение запускается, проверяется и собирается из файлов этого репозитория. Исходники движка находятся в `src/engine/`; генерация из внешней сборки, папки восстановления и серверные сервисы для этого не нужны.

## Запуск

Требуется Node.js 24.16.0 или новее.

```powershell
npm ci
npm run dev
```

Открыть **http://127.0.0.1:4192/**. Готовая сборка: `npm run build`, затем `npm run preview` и **http://127.0.0.1:4193/**. `dist/` можно разместить на обычном статическом хостинге. Для корректных ES-модулей открывайте через HTTP, а не `file://`.

При локальном запуске разные порты изолируют сохранения от резервной версии. Используются прежние формат `{S, at}` и ключи профиля. При публикации на прежний origin профиль продолжает использоваться; подробности ниже.

## Проверки

| Команда | Назначение |
|---|---|
| `npm run check` | Самодостаточность модулей, отсутствие старых ресурсов, типы и локальные тесты |
| `npm run build` | Проверка самостоятельности и production-сборка |
| `npm run verify:build` | Границы dist и сравнение минифицированных EN/RU/ES/FR/DE с собственными исходниками |
| `npm run test:equivalence` | Замороженные точные результаты оригинального движка; оригинальные файлы не требуются |
| `npm run test:oracle -- <путь-к-архиву>` | Необязательная сверка с явно указанным историческим архивом |

Результаты и границы доказанного совпадения: [движок и проверка независимости](docs/independent-engine.md), [описание тестов](docs/testing.md), [проверка остаточных ссылок](docs/reference-audit-2026-11-02.ru.md).

## Возможности

- Рождение → страна → свидетельство → жизнь → итоги → награда → следующая жизнь.
- Вкладки Life, People, Activities, Money и Odds; пауза, скорости, решения и автоматическое завершение жизни.
- Английский, русский, испанский, французский и немецкий; выбор валюты, эпохи и длительности жизни.
- Мобильная мета-экономика, локальный архив и восстановление жизни после перезагрузки.
- Портретный макет 393 × 852, поддержка ширины 320–430 CSS-пикселей и reduced motion.

Облако, публикации, социальные реакции, платёжный сервер и внешняя аналитика не подключены. Сохранения зависят от браузера и origin; очистка данных сайта удалит локальный прогресс. Разбор этих возможностей и того, что может понадобиться дальше: [аудит сервисов](docs/service-audit-2026-11-02.ru.md).

## Что находится внутри

- `src/engine/game.<lang>.js` — собственные локальные исходники симуляции и необходимых таблиц на пяти языках.
- `src/engine/era.js` — локальные данные прошлых и будущих эпох.
- `src/engine/state-effects.js` — изменения состояния, которые прежде делала старая отрисовка, без старых экранов и рисования.
- `src/core/` — управляемые часы, RNG, хранилище и хост движка; `src/adapters/` — команды и данные экранов.
- `src/screens/`, `src/ui/`, `src/flow/` — сохранённый мобильный интерфейс и flow.
- `tests/fixtures/` — небольшие контрольные данные; `tools/verification/` — необязательные сравнения для разработки.

Документация: [архитектура](docs/architecture.md), [экраны](docs/screen-map.md), [движение](docs/motion-spec.md), [языки](docs/localization.md), [журнал команд](docs/replay-format.md), [проверки](docs/testing.md), [переход репозитория](docs/github-migration.md).

## GitHub и публикация

Репозиторий: [paul-martyn/one-in-eight-billion-mobile](https://github.com/paul-martyn/one-in-eight-billion-mobile). Изменения проходят через pull request в `develop`; `CI` выполняет локальные проверки, сборку и 55 сценариев для минифицированных модулей. Отправка в `release` запускает публикацию GitHub Pages только после этих проверок. Относительный `base: './'` позволяет размещать `dist/` в пути репозитория. Прежний опубликованный исходный код сохранён в [резервной ветке](https://github.com/paul-martyn/one-in-eight-billion-mobile/tree/codex/generated-core-fallback-2026-11-02).

Форматы сохранений и ключи хранилища сохранены. Порты 4192/4193 отделяют локальную разработку от прежней версии. На GitHub Pages разные пути одного домена используют общее хранилище: для параллельных независимых тестов нужен другой origin или профиль браузера.

## Материалы и проверенное поведение

Сведения о происхождении кода и данных сохраняются в [уведомлении](licenses/ENGINE-SOURCE-NOTICE.md) и [технической истории](docs/independent-engine.md). Самостоятельность сборки описывает технические зависимости; алгоритмы и тексты сохраняют документированное происхождение. Лицензии четырёх используемых шрифтов находятся в `public/licenses/`.

Тесты проверяют полное состояние, RNG, сохранение и восстановление, действия адаптера и production-сборку. Они подтверждают перечисленные сценарии; все вероятностные ветки не перебираются. Известные ограничения replay последующих жизней и Retry после fatal-ошибки перечислены в [описании движка](docs/independent-engine.md).
