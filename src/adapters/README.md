# Граница подключения core

Адаптер подключает мобильный UI к самостоятельным исходникам движка `src/engine/`, выделенным из версии 0.8.98. `boot.ts` создаёт единственный экземпляр `GameAdapter`; `gameAdapter.ts` управляет командами, часами, сохранением и read-only снимками для экранов.

Экран получает view model и передаёт типизированное действие. `commands.ts` повторяет порядок вызовов игровых обработчиков; `vm/` получает данные через песочницу чтения core. Нельзя заново реализовывать формулы в React, заменять оригинальные вероятности или продвигать симуляцию из render/effect экрана.

Браузер импортирует `src/engine/game.<lang>.js` и локальный модуль ERA. При запуске и сборке файлы оригинала не читаются, генерации из снимка нет. Старые экраны и их сетевые сервисы удалены из движка; прежние эффекты отрисовки на состояние воспроизводит `src/engine/state-effects.js`. `src/fixtures` остаётся материалом для изолированных макетов и не подменяет ошибки настоящего адаптера.

Ключи `one8b.*` и префикс `1in8b-mobile/v1:` сохраняют совместимость существующих сохранений; их переименование требует отдельной миграции. Отдельные порты эксперимента изолируют браузерный профиль от резервной версии. Происхождение и границы паритета описаны в `docs/independent-engine.md`, проверки — в `docs/testing.md`.
