# Граница подключения core

Рабочего адаптера пока нет. `reference/original-0.8.98` не импортируется и не выполняется.

После получения карты экранов здесь появится единственная точка связи UI с оригинальной симуляцией. Экран получает view model и передаёт действие; чтение `S`, вызовы оригинальных функций и преобразование ответа выполняются адаптером. Нельзя заново реализовывать формулы в React, заменять оригинальные вероятности или продвигать симуляцию из render/effect экрана.

Конкретный контракт действий будет определён при подключении первого настоящего экрана. До этого `src/fixtures` содержит только статические данные представления.
