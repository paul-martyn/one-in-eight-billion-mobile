Этот снимок не присваивает игровому коду новую общую лицензию. Он подготовлен по запросу заявленного автора для восстановления собственного проекта. Оригинальные публичные условия сохранены в `raw/1in8b.life/en/terms/index.html` (получены 31 октября 2026).

Игровые тексты/код и сторонние статистические данные имеют разные условия. На публичном сайте отдельная открытая лицензия исходного репозитория не обнаружена. Полная привязка каждого числа к исходной выгрузке и её лицензии не восстановлена.

Ссылки и подписи источников сохранены в `catalogs/source-attributions.en.json`, `catalogs/external-links.json` и оригинальных страницах. Сайт называет UN WPP 2024, UN IGME, World Bank WDI, WHO, UNESCO UIS, UNDP, ILO, UNAIDS, UNODC, UNICEF, WHR/OWID, Maddison, UCDP/PRIO и Lee-Lee. В его атрибуции указаны CC BY 4.0 для ряда источников и CC BY 3.0 IGO для UN; это не универсальная лицензия на любой параметр игры.

Уведомления Acorn 8.15.0 (MIT), Prettier 3.6.2 (MIT и THIRD-PARTY-NOTICES) сохранены в `licenses/`. Они относятся к инструментам восстановления. Node.js устанавливается отдельно.

Полные SIL OFL 1.1 для Hahmlet, IBM Plex Sans KR, IBM Plex Mono, IBM Plex Sans Arabic и Nanum Pen Script находятся в `licenses/fonts/`. Эти уведомления перенесены из предыдущего проверенного пакета от 29 октября; исходные URL: `https://github.com/google/fonts/tree/main/ofl/` с каталогами `hahmlet`, `ibmplexsanskr`, `ibmplexmono`, `ibmplexsansarabic`, `nanumpenscript`. Соответствие subset-файлов конкретному upstream-коммиту не установлено. Все 665 WOFF2 совпадают с прежним снимком.

Статические документы Engine API сохранены для изучения контракта. Рабочие ответы API и ключи в пакет не входят. Полные актуальные на момент снимка формулировки условий доступны в сохранённых HTML, а не заменяются этим кратким описанием.
