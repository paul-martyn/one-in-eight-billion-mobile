# Проверки экспериментальной версии

`npm test` работает из этого каталога без соседних проектов и recovery-папок.

Проверки охватывают переводы интерфейса, ориентацию, точность генератора случайности, однократное применение команд, изоляцию чтений экранов, покупки и настройки, replay, восстановление сохранения, валюты и смену языка. Для каждого из пяти языков проверяется путь рождения, четырёх сопутствующих жизней, свидетельства, жизни до смерти, награды, перезагрузки и следующей жизни.

`tests/fixtures/engine-regressions.json` содержит небольшие контрольные результаты, полученные из неизменённых опубликованных сборок 0.8.98 при фиксированных часах и seed. Сами сборки для обычного теста не требуются. Проверяются точные SHA-256 сериализованного состояния целиком, счётчик RNG и наблюдения HOOK после 15 полных жизней: 11 английских сценариев с разными странами, стратегиями выбора, прошлым и будущим, плюс по одной жизни остальных четырёх языков. Менять эти хеши только ради прохождения теста нельзя.

Ещё пять контрольных сценариев `render-themes.test.mjs` проверяют полное состояние и RNG до и после тематического решения. Они защищают происхождение тематических отметок дневника: удаление старого рендера не должно переносить отметку с результата выбора на сам вопрос. Защитные тесты модулей и ресурсов дополнительно проверяют самостоятельность исходников и production-сборки, включая отклонение зависимостей от снимков и удалённых скриптов.

Обе замороженные группы воспроизводят среду захвата `Europe/Minsk` через `tests/frozen-environment.mjs`. Часовой пояс здесь — ещё и вход локализации: `Intl` участвует в выборе валюты и регионального текста помощи, даже если часы и seed зафиксированы. Без этого на UTC менялись поля `S.log[].fact` и часть валютных значений; все исходные ожидаемые хеши сохранены. Настройка действует только в отдельных Node-процессах этих двух тестовых файлов, не меняя браузерную игру или сравнительные сценарии.

Дополнительная проверка против исходных сборок запускается явно:

Если исторический проект получен чистым checkout резервной ветки, сначала внутри него выполняются `npm ci` и `npm run core:extract`: прежнему harness нужны его локальные метаданные `*.core.meta.json`, не хранящиеся в Git. Это подготовка только необязательного эталона; текущее приложение и его CI такую генерацию не используют. Инструмент проверяет наличие этих файлов и объясняет отсутствие до запуска сценариев.

```powershell
npm run test:oracle -- <путь-к-сохранённому-архиву>
```

Она требует явно указанный сохранённый мобильный проект как внешний инструмент разработки. Без аргумента или `INDEPENDENT_BASELINE` инструмент завершается с объяснением; автоматического поиска соседнего каталога нет. Этот путь не используется приложением, сборкой или обычными тестами. Сначала выполняются 55 полных жизней: все 11 сценариев на каждом из пяти языков. После каждой команды сравниваются полное состояние, счётчик RNG, число HOOK-вызовов и ошибки, затем записи хранилища. После этого исходные тесты обработчиков проверяют свидетельство, начало жизни, решения, кадры, скорость, паузу, покупки, настройки и завершение жизни через собственные адаптеры экспериментальной версии.

Для одного сценария:

```powershell
node --experimental-strip-types tools/verification/compare-engines.mjs --baseline <путь-к-архиву> --langs en --scenario can-f-auto
```

Отчёт создаётся в `artifacts/oracle-comparison.json`. Изменение пути эталонного проекта задаётся `--baseline` для comparator либо первым аргументом `run-oracle-tests.mjs`. Сравнение не изменяет соседний проект или исходные снимки и не обращается к сети.

Эти проверки подтверждают конкретные воспроизводимые сценарии. Они не перебирают каждую вероятностную ветку игры.

Итоговая проверка 2 ноября: 65 локальных тестов, 55 сценариев против оригинальных сборок, 19 проверок исходных обработчиков и 55 сценариев source-versus-minified — все прошли. Точные сведения и хеши: verification-summary.json. Шесть тестов era-restore проверяют восстановление прошлой/будущей жизни, смену валюты и языка до расчётов; пять render-themes фиксируют исходные состояния дневника.

После дополнительной очистки сервисных переводов перед обновлением GitHub повторно прошли 66 локальных тестов, 55 сценариев против исторического снимка, 19 проверок обработчиков и 55 сценариев production. Актуальные исходные хеши и проверка чистого дерева Git фиксируются в `github-migration-verification.json`; предыдущий `verification-summary.json` остаётся отчётом этапа выделения.
