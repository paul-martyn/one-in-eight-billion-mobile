# Локализация мобильной игры

1 ноября 2026. Поддерживаются `en`, `ru`, `es`, `fr`, `de`.

## Интерфейс

В `src/i18n/<locale>/` по 18 файлов экранов: 533 базовых ключа, дополнительно русские формы чисел. `t` подставляет значения и выбирает форму через `Intl.PluralRules`. Если ключ пропущен, используется английский текст, а неизвестный ключ виден как `[key]`. Тест проверяет полное покрытие, дубликаты и совпадение подстановок.

`mobile.locale` в пространстве `1in8b-mobile/v1:` сохраняет явный выбор. Без него выбирается первый поддерживаемый язык из `navigator.languages`, иначе английский. На экране Language перевод меню предварительно меняется сразу; язык core и валюта применяются вместе по Continue. После успеха выбор сохраняется. При отказе загрузки прежний core остаётся доступен, на экране можно повторить попытку.

Валюта выбирается из набора оригинала для выбранного языка. У испанского оригинала отдельные `ES_CURS` / `one8b.escur`, у остальных — `CUR_SETS[lang]` / `one8b.cur.<lang>`. Числа и даты интерфейса форматируются текущей локалью, а суммы и игровые описания — оригинальными функциями core.

## Кириллический шрифт

Стек интерфейса — `Fredoka, Rubik, 'Baloo 2', system-ui, sans-serif`, одинаковый в CSS и токенах дизайна. Латинские буквы остаются во Fredoka; кириллицу браузер автоматически берёт из Rubik, поскольку во Fredoka её нет. Это работает для русского, украинского и белорусского текста независимо от выбранной локали. Поддержка шрифта не добавляет новые переводы: набор языков игры остаётся прежним.

В `src/main.tsx` подключены только `@fontsource/rubik/cyrillic-500.css`, `cyrillic-600.css` и `cyrillic-700.css`, с теми же весами 500/600/700, что и у Fredoka. Версия пакета закреплена: `5.3.0`. Основной набор `cyrillic` содержит в том числе `ґ`, `є`, `і`, `ї`, `ў`; `cyrillic-ext` не подключается. Отдельный загрузчик и переопределение всего шрифта для русской локали больше не нужны. В свидетельствах латиница остаётся в Courier Prime, кириллица получает запасной Rubik; рукописная подпись — Caveat с существующей кириллицей.

Файлы включаются в сборку, внешних запросов к Google Fonts или CDN нет. Лицензия OFL-1.1 сохранена в пакете и `public/licenses/rubik-OFL.txt` (попадает в сборку). Выбор Rubik соответствует описанию дизайна v109 в `mobile-mockups/production-ui/README.md` родительского рабочего пространства; снимок `design/claude-canvas` v107 не изменяется.

## Игровые тексты

Для каждого языка загружается отдельный производный core с оригинальным словарём и грамматическими функциями. Загрузка отложенная: остальные языковые сборки при старте не скачиваются.

Английский и русский берутся из неизменяемого `reference/original-0.8.98/src/`. Три дополнительные точные публичные сборки из локального снимка `recovery-life-2026-10-31` сохранены отдельным новым снимком `reference/locales-0.8.98/`; их происхождение, длина и SHA-256 — в `reference/locales-provenance.json`. Применимы уведомления о лицензиях исходного снимка `reference/original-0.8.98/LICENSES.md`. Исходный эталон и его provenance не менялись. Генератор только добавляет прежнюю обёртку; тела всех сборок остаются побайтно неизменными.

При переключении новый core получает тот же `S`, состояние `CoreEntropy` из сохранения и `RND_N`. Не вызываются `restore`, `newLife` и `renderAll`; не разыгрываются новый персонаж или номер свидетельства. Жизнь остаётся на паузе, ускорение снимается, как при прежней смене валюты. Представления пересчитываются в песочнице. Журнал воспроизведения завершается, поскольку он привязан к одной конкретной языковой сборке.

## Сохранения

Оригинал разделял жизни и архивы по языкам. Хост переводит ключи `one8b.<lang>.(save|lives|past|unlived).*` поддерживаемых языков в прежние английские ключи. Поэтому старые сохранения мобильного клиента продолжают работать, архив и мета-экономика не дублируются. Валюты и настройки остаются в собственных ключах. В приватном режиме одна общая память используется для всех смен языка до закрытия страницы.

Оригинальный формат `S` хранит готовый текст журнала, текущего решения, городов, некоторых описаний и архива. Уже записанный текст не переводится задним числом: это потребовало бы изменения формата сохранения либо повторной симуляции. Экран выбора языка объясняет это, если жизнь уже начата. Новые события, решения, подписи и представления создаются на выбранном языке.

## Проверки

Русский интерфейс обращается на «вы», как игровые события. Названия стран в новых формулировках стоят в именительном падеже; пол персонажа не подменяется мужским обращением. Для итогов наград число `count` передаётся отдельно от форматированной суммы, чтобы работали формы «1 кристалл», «2 кристалла», «5 кристаллов».

Поисковые фразы русских родственников формируются в `peopleVM` через штатную грамматику core: «ваша мать», «вашей матери», «ваш отец», «вашего отца» и т. д., включая записи памяти. Интерфейс использует готовые фразы; редактура обычных UI-строк не влияет на этот поиск. Резервный русский `people.yourRole` содержит только название роли. Точечные поправки текстов симуляции описаны в [происхождении core](core-derivation.md).

`npm run check` и `npm run build` включают проверку обоих снимков, генерацию и типы. Дополнительно:

- `tests/i18n.test.mjs`: покрытие всех пяти словарей, параметры, региональные языки, восстановление выбора, русские формы 1/2/5/11/21/22 и анимация локализованных чисел.
- `tests/core/localization.test.mjs`: полная жизнь на каждом языке против неизменённого оригинала; сравнение `S`, RNG и HOOK после каждой команды; цикл переключения en → ru → es → fr → de → en, архив, энергия, свидетельство, перезагрузка и отказ загрузки.
