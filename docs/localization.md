# Локализация мобильной игры

Мобильный слой локализации введён 1 ноября 2026 года; документ адаптирован для самостоятельной версии 2 ноября. Поддерживаются `en`, `ru`, `es`, `fr`, `de`. Исходный текст и его SHA-256 сохранены в [описи документации](documentation-import-2026-11-02.json).

## Интерфейс

В `src/i18n/<locale>/` по 18 файлов экранов: 533 базовых ключа, дополнительно русские формы чисел. `t` подставляет значения и выбирает форму через `Intl.PluralRules`. Если ключ пропущен, используется английский текст, а неизвестный ключ виден как `[key]`. Тест проверяет полное покрытие, дубликаты и совпадение подстановок.

`mobile.locale` в пространстве `1in8b-mobile/v1:` сохраняет явный выбор. Без него выбирается первый поддерживаемый язык из `navigator.languages`, иначе английский. На экране Language перевод меню предварительно меняется сразу; язык core и валюта применяются вместе по Continue. После успеха выбор сохраняется. При отказе загрузки прежний core остаётся доступен, на экране можно повторить попытку.

Валюта выбирается из набора оригинала для выбранного языка. У испанского оригинала отдельные `ES_CURS` / `one8b.escur`, у остальных — `CUR_SETS[lang]` / `one8b.cur.<lang>`. Числа и даты интерфейса форматируются текущей локалью, а суммы и игровые описания — оригинальными функциями core.

## Кириллический шрифт

Стек интерфейса — `Fredoka, Rubik, 'Baloo 2', system-ui, sans-serif`, одинаковый в CSS и токенах дизайна. Латинские буквы остаются во Fredoka; кириллицу браузер автоматически берёт из Rubik, поскольку во Fredoka её нет. Это работает для русского, украинского и белорусского текста независимо от выбранной локали. Поддержка шрифта не добавляет новые переводы: набор языков игры остаётся прежним.

В `src/main.tsx` подключены только `@fontsource/rubik/cyrillic-500.css`, `cyrillic-600.css` и `cyrillic-700.css`, с теми же весами 500/600/700, что и у Fredoka. Версия пакета закреплена: `5.3.0`. Основной набор `cyrillic` содержит в том числе `ґ`, `є`, `і`, `ї`, `ў`; `cyrillic-ext` не подключается. Отдельный загрузчик и переопределение всего шрифта для русской локали больше не нужны. В свидетельствах латиница остаётся в Courier Prime, кириллица получает запасной Rubik; рукописная подпись — Caveat с существующей кириллицей.

Файлы включаются в сборку, внешних запросов к Google Fonts или CDN нет. Лицензия OFL-1.1 сохранена в пакете и [public/licenses/rubik-OFL.txt](../public/licenses/rubik-OFL.txt), который попадает в сборку. Выбор Rubik был принят для мобильного дизайна v109; сохранённый локально [холст v107](../design/claude-canvas/) не изменяется. Упоминание v109 описывает историю решения, а не дополнительную зависимость запуска.

## Игровые тексты

Для каждого языка отложенно загружается собственный локальный модуль `src/engine/game.<lang>.js` со словарём и грамматическими функциями. Остальные языки при старте не загружаются.

Историческая основа пяти модулей — опубликованные сборки 0.8.98 beta, сохранённые 31 октября 2026 года. В самостоятельном проекте из них выделен нужный подграф игровой логики; старый UI, загрузчики и сервисные части удалены, поэтому нынешние модули не являются побайтными копиями исходных сборок. Исходные размеры и SHA-256 не заменяются хешами новых файлов: происхождение описано в [independent-engine.md](independent-engine.md), точная опись — в [engine-extraction.json](engine-extraction.json), уведомление — в [ENGINE-SOURCE-NOTICE.md](../licenses/ENGINE-SOURCE-NOTICE.md). Для обычного запуска и сборки нужны только файлы этого проекта.

При переключении новый экземпляр получает тот же `S`, состояние `CoreEntropy` из сохранения и `RND_N`. Новый персонаж и номер свидетельства не разыгрываются, новая жизнь не создаётся. До переноса жизни прошлого или будущего хост загружает локальную ERA, чтобы функции стран и экономики сразу видели правильную эпоху. Жизнь остаётся на паузе, ускорение снимается. Представления пересчитываются в песочнице. Журнал воспроизведения завершается, поскольку он привязан к одной конкретной языковой сборке.

## Сохранения

Оригинал разделял жизни и архивы по языкам. Хост переводит ключи `one8b.<lang>.(save|lives|past|unlived).*` поддерживаемых языков в прежние английские ключи. Поэтому старые сохранения мобильного клиента продолжают работать, архив и мета-экономика не дублируются. Валюты и настройки остаются в собственных ключах. В приватном режиме одна общая память используется для всех смен языка до закрытия страницы.

Оригинальный формат `S` хранит готовый текст журнала, текущего решения, городов, некоторых описаний и архива. Уже записанный текст не переводится задним числом: это потребовало бы изменения формата сохранения либо повторной симуляции. Экран выбора языка объясняет это, если жизнь уже начата. Новые события, решения, подписи и представления создаются на выбранном языке.

## Проверки

Русский интерфейс обращается на «вы», как игровые события. Названия стран в новых формулировках стоят в именительном падеже; пол персонажа не подменяется мужским обращением. Для итогов наград число `count` передаётся отдельно от форматированной суммы, чтобы работали формы «1 кристалл», «2 кристалла», «5 кристаллов».

Поисковые фразы русских родственников формируются в `peopleVM` через штатную грамматику движка: «ваша мать», «вашей матери», «ваш отец», «вашего отца» и т. д., включая записи памяти. Интерфейс использует готовые фразы; редактура обычных UI-строк не влияет на этот поиск. Резервный русский `people.yourRole` содержит только название роли. Точечные поправки находятся в [локальном модуле ru.ts](../src/core/localization/ru.ts); границы переноса описаны в [происхождении движка](independent-engine.md).

`npm run check` проверяет замкнутые зависимости локального движка, типы и самостоятельные тесты. `npm run build` собирает собственные исходники; извлечение кода из снимков не требуется. Дополнительно:

- `tests/i18n.test.mjs`: покрытие всех пяти словарей, параметры, региональные языки, восстановление выбора, русские формы 1/2/5/11/21/22 и анимация локализованных чисел.
- `tests/core/localization.test.mjs`: жизнь от рождения до смерти на каждом языке, четыре сопутствующие жизни, награда, следующая жизнь; цикл en → ru → es → fr → de → en, архив, энергия, свидетельство, перезагрузка и отказ загрузки.
- `tests/core/regressions.test.mjs` и `render-themes.test.mjs`: замороженные результаты исходного движка, включая полное `S`, RNG и тематические отметки дневника. Исходные сборки для этих тестов не нужны.
- Дополнительная прямая сверка 55 сценариев с историческими сборками доступна через `npm run test:oracle` только при наличии внешнего эталона разработки. Это отдельная проверка, а не зависимость локализации или сборки. Подробнее — [testing.md](testing.md).
