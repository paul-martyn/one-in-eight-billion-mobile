# Спецификация движения

Перенесена из мобильного интерфейса от 1 ноября 2026 года; исходный документ и его SHA-256 зафиксированы в [описи переноса документации](documentation-import-2026-11-02.json). Параметры движения сохранены. Подключение самостоятельного движка описано в [архитектуре](architecture.md).

Источник истины — [`src/design/motion.json`](../src/design/motion.json): длительности, задержки, кривые, начальные и конечные значения, политика прерывания и ввода. Веб-интерфейс читает этот файл напрямую. Для Unity он служит таблицей параметров; React, CSS и Motion автоматически в Unity не переносятся.

## Система координат

Все смещения заданы в CSS-пикселях портретного кадра 393 × 852 или в процентах кадра (`"100%"` — полный кадр). В Unity используйте опорное разрешение 393 × 852 с подгонкой по ширине и переводите пиксели в единицы канваса в том же масштабе.

## Переходы экранов (`screenTransitions`)

| id | Когда | Длительность | Кривая | Входящий экран | Уходящий экран |
|---|---|---|---|---|---|
| `screen.fade` | по умолчанию | 380 мс | ease | прозрачность 0 → 1 | без изменений, снимается по завершении |
| `screen.tab` | вкладки жизни | 220 мс | ease | прозрачность 0 → 1 | стикер-меню остаётся на месте |
| `screen.rise` | Life → итоги жизни | 520 мс | cubic-bezier(.22,1,.36,1) | сдвиг Y 100% → 0 | — |
| `screen.birth` | Roll → Certificate (Meet me!) | 240 мс | ease | прозрачность 0 → 1 за 240 мс: «бумага» рождения проявляется над планетой; рождение начинается после перехода | прозрачность 1 → 0 за 200 мс |
| `screen.push` | Certificate → Your odds | 440 мс | то же | сдвиг X 100% → 0 | X 0 → −30%, яркость 1 → 0,8 |
| `screen.pop` | назад | 440 мс | то же | X −30% → 0, яркость 0,8 → 1 | X 0 → 100%, поверх входящего |
| `screen.zoom` | Certificate/Odds → Life | 480 мс | ease-out | прозрачность 0 → 1, масштаб 1,08 → 1 | — |
| `screen.glide` | между экранами с общей планетой (Language, Start, Roll, Hub) | 760 мс | ease | прозрачность 0 → 1 за 460 мс после 220 мс | прозрачность 1 → 0 за 320 мс |

**Общая планета.** Под экранами Language, Start, Roll и Hub живёт одна планета (`src/flow/PlanetStage.tsx`): при `screen.glide` интерфейсы сменяются, а планета за 750 мс перелетает на место следующего экрана и не перестаёт вращаться. Экран с планетой не сдвигается вбок: `push` к нему и `pop` от него показываются как `fade`, а при возврате `pop` на него уезжает только уходящий экран. После экранов без планеты она появляется сразу на месте и проявляется вместе с новым экраном (380 мс).

**Прерывание.** Новая навигация во время перехода мгновенно завершает текущий переход и запускает следующий от нового текущего экрана. Уходящий экран снимается по таймеру длительности, а не по событию окончания анимации.

**Ввод.** Принимает только входящий экран. Уходящий экран получает `inert` и `pointer-events: none`.

**Сокращённое движение.** Переход длится 0 мс, состояние то же.

## Последовательности

| Ключ | Что | Ключевые параметры |
|---|---|---|
| `roll` | рулетка страны | старт через 400 мс; вращение 4600 мс, 3 оборота, ease-out-quart; приближение ×2,4; появление ответа через 1300 мс после остановки |
| `certificate` | рождение и свидетельство (дубль Б2) | фазы 80 / 200 / 380 / 950 / 1150 / 2050 мс, печать с 2600 мс по 9 знаков каждые 25 мс; малыш появляется на месте планеты рулетки и за 600 мс улетает в фотоуголок, где остаётся фотографией; свидетельство выезжает за 550 мс; штамп 1,7 → 1 за 350 мс. Тап: до свидетельства — сразу к нему (полёт и выезд 350 мс) и печать по 40 знаков; во время печати — всё сразу. Возврат с «Your odds» и сокращённое движение — готовое свидетельство |
| `countUp` | счётчики при появлении | 900 мс, ease-out-cubic; при сокращённом движении — сразу итог |
| `hubArrive` / `hubLeave` | хор хаба | верх −150 → 0 (400 мс), счётчики +24 → 0, кнопка 0,8 → 1, меню +140 → 0; уход в обратном порядке с ускорением, переход через 800 мс |
| `sticker` | активный стикер | масштаб 1 → 1,1 (пружина 250 мс), покачивание 400 мс, заливка 200 мс, кольцо 400 мс, 6 искр 500 мс по фиксированным смещениям |
| `popup` | окна решения и паузы | появление 220 мс (масштаб 0,94 → 1), исчезновение 140 мс, затемнение 180 мс. В макете окна появлялись мгновенно; короткое появление добавлено, чтобы решение не «мигало». Игра его не ждёт |
| `journalEntry` | новая запись журнала | 260 мс, Y −8 → 0; история показывается без анимации |
| `death` | смерть на экране жизни (v107) | замирание: пауза, скорость и меню скрыты, сцена приглушена; через 900 мс (тап ускоряет) — окно «Life ended»; кнопки активны через 500 мс; удержание пальца на пустом месте прячет окно, пока палец лежит. Look back → итог «выезжает снизу» (`rise`) |
| `lifeReward` | хаб после жизни (v107) | окно «A life lived» через 800 мс после прихода хаба; Claim активен через 450 мс; после Claim окно гаснет, монеты и кристаллы летят в счётчики, счётчики досчитываются (`countUp`), портрет летит во вкладку Lives, появляется бейдж. При сокращённом движении полётов нет, числа меняются сразу |

Анимации смерти и наград только показывают уже наступившее состояние: смерть произошла в core до первого кадра окна, а Claim зачисляет награду до начала полёта монет.

## Случайность в движении

Вспышки рождений на планете, искры и задержки используют `Math.random` браузера. Игровой поток локального движка от них не зависит: хост связывает его `Math.random` с `CoreEntropy`, а чтения представления — с отдельным источником. Рулетка страны ничего не разыгрывает, она показывает уже выбранную движком страну. Смерть, Claim и переходы экранов не должны добавлять игровые броски RNG или шаги времени.
