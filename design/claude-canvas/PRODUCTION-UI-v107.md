# One in Eight Billion — production UI: экраны и переходы

Карта утверждённого мобильного интерфейса (cute / kawaii, только светлая тема) для интеграции с игровой логикой. Здесь нет симуляции: данные одной жизни (Аарав Шривастава, Лакхнау, 2026–2100) зашиты в экраны как пример.

- **Холст с макетами:** https://claude.ai/artifact/KGzMcdvdJ9JTkX25t2DdAv, лист **Production · UI flow** (открывается первым).
  - Артборд **Prototype** — все экраны в одном телефоне с анимированными переходами и боковой панелью для прыжков. Открывается кнопкой Play на его подписи.
  - Артборд **Flow map** — та же карта переходов стрелками.
  - Ряды ниже — каждый экран и его состояния отдельными артбордами.
  - Лист «Финал · Light / Dark» — эксперименты (тёмная тема, варианты меню, прежний экран смерти), не для интеграции.
- **Копия исходников рядом с этим файлом** (снимок версии 107 холста):
  - `screens/*.dc.html` — экраны;
  - `tools/` — генераторы и проверка.
- Размер экрана: 393 × 852 CSS px, портрет.

## Экраны

| Файл (stem) | Экран | Состояния (prop `frame` и др.) | Кнопки → куда |
|---|---|---|---|
| `LangCute` | Язык и валюта: 19 языков, валюты квадратами, экран сразу переводится | — | Continue → `StartCute` (при первом запуске) или назад в `HubCute` (если открыт из настроек хаба) |
| `StartCute` | Старт: крутящаяся планета, счётчики «родилось / умерло с момента запуска» | — | Be Born! → `RollCute` |
| `RollCute` | Выбор страны: глобус крутится ~4,6 с, затем «You are born in India», город | — | Who am I? → `CertCute`; кнопка повтора спина |
| `CertCute` | Свидетельство о рождении: родители, «рождение», текст печатается, печать | `play` (по умолчанию, вся анимация), `parents`, `born`, `certificate` (сразу заполнено) | Your odds → `OddsCute`; Start life → `LiveCute` |
| `OddsCute` | Ваши шансы: статы, факты о стране | `layout: phone/full` | ← назад → `CertCute`; Start life → `LiveCute` |
| `LiveCute` | **Жизнь**: шкала возраста (до 100, метка ожидаемых 71), статы, журнал, нижнее меню-стикеры | `journal`, `decision` (попап «Dad asks»), `pause` (попап паузы), `died` (смерть). Также `ended` — в флоу не используется | см. ниже |
| `PeopleCute` | Люди: список → карточка человека | `list`, `person` | стикеры меню |
| `ActivitiesCute` | Занятия: действия открываются игровыми попапами | `main`, `detail`, `started` | стикеры меню |
| `MoneyCute` | Деньги: сводка, сбережения (попап) | `main`, `detail` | стикеры меню; ссылки внутри → `ActivitiesCute`, `PeopleCute` |
| `OddsLife` | Шансы в жизни: кривая выживаемости, «рождённые в ту же секунду» | `survival`, `lives` | стикеры меню |
| `EndCute` | Итоги жизни «This life»: фото, имя, годы, одна строка биографии, возраст и ожидаемые 71, главы; раскрываемые блоки (как закончилась жизнь + статистика причины, последний год, люди, имущество) | — | To the hub → `HubCute` с наградами |
| `HubCute` | Хаб между жизнями: энергия / доллары / гемы (у каждой «+»), настройки, планета, счётчики, Be Born! (−1 энергия), вкладки Shop / World / Lives | `rewards: on` (после жизни: попап наград), `demo: on` (вкладки листаются сами) | шестерёнка → `LangCute`; Be Born! → `RollCute` |

Обёртки — отдельные артборды с другим состоянием, логики в них нет: `LiveCuteDecision`, `LiveCutePause`, `LiveCuteDied`, `PeopleCutePerson`, `ActivitiesCuteDetail`, `ActivitiesCuteStarted`, `MoneyCuteDetail`, `OddsLifeLives`, `HubCuteRewards`.

## Маршруты

```
Первый запуск:  LangCute → StartCute → RollCute → CertCute ─┬→ OddsCute → LiveCute (попап «Dad asks»)
                                                            └────────────→ LiveCute (попап «Dad asks»)
Жизнь:          LiveCute ⇄ PeopleCute / ActivitiesCute / MoneyCute / OddsLife   (стикеры меню, все со всеми)
Пауза:          LiveCute: пауза → попап [Resume | Exit to hub → HubCute | Skip to the end → смерть]
Смерть:         LiveCute (frame died) → Look back → EndCute → To the hub → HubCute (rewards on) → Claim
Новая жизнь:    HubCute → Be Born! → RollCute → CertCute → … (дальше как первый запуск)
Настройки:      HubCute → шестерёнка → LangCute → Continue → HubCute
```

## Что происходит внутри экранов

- **Попап решения** (`LiveCute`, новая жизнь). Вопрос «Dad asks…» с тремя вариантами. После выбора показывается ответ и последствия, затем «Continue». Жизнь пошла: запись в журнале, изменения статов и денег.
- **Пауза.** Круглая кнопка паузы открывает игровой попап с кнопками Resume и Exit to hub, рядом Skip to the end и розовый крестик (тоже Resume). Пока открыт попап решения, паузы нет.
- **Смерть** (`frame: died`, или Skip to the end):
  1. Жизнь замирает: пауза, скорость и меню скрываются, возраст стоит на 74, в журнале финальная сиреневая запись, сцена приглушается.
  2. Через **0,9 с** (тап ускоряет) жизнь накрывает экран смерти почти чёрного фиолетового цвета: черепок, красное «Life ended», портрет с именем и годами, карточка причины.
  3. Кнопки становятся активны через 0,5 с.
  4. **Удержание пальца на пустом месте** прячет экран, пока палец лежит, — «посмотреть последний день».
  5. Look back → `EndCute`.
- **Хаб после жизни** (`rewards: on`):
  1. Хаб въезжает: верхняя панель сверху, вкладки снизу, валюты считаются.
  2. Через 0,8 с открывается попап «A life lived»: портрет, имя и годы, список наград за действия в жизни, итог «+250 $ · +2 гема». Кнопка **Claim** — единственная, активна через 0,45 с.
  3. По Claim попап гаснет, монеты и гемы летят в счётчики, а те досчитываются. Портрет улетает во вкладку **Lives**, на ней появляется бейдж «1».
- **Be Born! в хабе.** Гаснет ячейка энергии, верх уезжает вверх, меню вниз, остаётся только планета. Она стоит там же, где у `RollCute`, и начинается спин.
- **Вкладки хаба.** Shop / World / Lives пока только переключаются, содержимое экрана не меняется (Shop и Lives — заглушки).
- **Появление экранов.** Бары растут от 0, числа и проценты считаются вверх примерно за 0,9 с.

## Переходы в прототипе

| Откуда → куда | Анимация |
|---|---|
| между Life и вкладками | быстрый crossfade 220 мс, стикерное меню стоит на месте |
| `RollCute` → `CertCute` | свидетельство выезжает снизу |
| `CertCute` ⇄ `OddsCute` | сдвиг в сторону (push / pop) |
| `CertCute` / `OddsCute` → `LiveCute` | лёгкий zoom-in |
| `LiveCute` → `EndCute` | итоги выезжают снизу |
| `HubCute` → `RollCute` | хаб прячет свой интерфейс, затем crossfade (планета на месте) |
| `HubCute` ⇄ `LangCute` | push / pop |
| остальное | fade 380 мс |

## Контракт навигации в макетах

- Каждый экран навигирует через `linkTo(this, 'Stem')`: на холсте это обычная ссылка `Stem.dc.html`, а внутри прототипа экран получает prop `nav` (функция). Тогда ссылки отключаются, и нажатие вызывает `nav('Stem')`.
- Стикерное меню строится `stickerLinks(this)`.
- Хост (`Prototype.dc.html`) сам решает, какой экран показать и с какой анимацией, и передаёт `frame` для Life (`decision` для новой жизни, `died` для смерти) и `rewards` для хаба. Если это переносить в приложение, `nav(stem)` и есть точка подключения роутера.

## Заглушки и чего нет

- **Кнопки без действия:** «+» у валют, Shop, содержимое вкладок Lives / Shop в хабе, кнопка меню (☰) в Life, статистика и ×скорость.
- **Данные зашиты в константы** в начале скрипта каждого экрана: `LATE`, `CHAPTERS`, `REWARDS`, `STAT`, `BASE`, `YEARS` и другие.
- **Портреты** — 15-летний Аарав (возрастных портретов нет). Картинки и фоны лежат на холсте как ассеты `/_blob/<id>`, исходники персонажей — в `character-art/`.
- **Нет:** короткой жизни (смерть ребёнка), «рождённых в ту же секунду» на возрасте смерти, ошибок сохранения, системного Back.
- **Наборы валют** для ko, ja, zh, vi, th, fa — заглушки. Остальные взяты из оригинальной игры.

## Визуальный язык (кратко)

- **Шрифт:** Fredoka 500/600/700.
- **Обводки:** коричневые `#7b4b2a`, 2 px.
- **Нажимаемое:** `inset 0 -3px 0 rgba(90,52,24,0.22)`; главные кнопки — жёлтые `#ffd75a` с белым бликом сверху.
- **Белые подписи с коричневым контуром:** классы `k-o`, `k-os`, `k-big`.
- **Игровые попапы:** оранжевая панель `#f4a940`, круглый значок сверху, бирюзовая лента `#3ec3d2`.
- **Фон:** `#f2e3c6`.
- **Бейдж уведомления:** красный `#f2384c`, белая цифра с контуром.

## Файлы

- `screens/` — все экраны и обёртки листа Production, плюс `Prototype.dc.html`, `FlowMap.dc.html` и компонент `Globe.dc.html`. Формат Design-холста: разметка в `<x-dc>`, `{{ дырки }}` из `renderVals()` в `<script data-dc-script>`.
- `tools/` — генераторы части экранов. Не правьте сгенерированные `.dc.html` руками, иначе правки пропадут при следующей генерации.
  - `menu-tabs3.js` + `base/LiveCute.base.dc.html` → `LiveCute`;
  - `tabs-common.js`, `sticker-nav.js`, `gen-people.js`, `gen-activities.js`, `gen-money.js`, `gen-odds.js` → вкладки;
  - `gen-flowmap.js` → карта;
  - `check-dc.js` — проверка экрана: логика в обычном и встроенном режиме, все дырки разрешаются. Пример: `node tools/check-dc.js screens/LiveCute.dc.html '{"frame":"died"}'`.
